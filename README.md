# Quio V2

Landing page premium para Quio, desarrollada únicamente con HTML5, CSS3 y JavaScript Vanilla.

## Publicación en GitHub Pages

1. Sube `index.html`, `styles.css` y `script.js` a la raíz del repositorio.
2. En GitHub, abre **Settings → Pages**.
3. Selecciona la rama principal y la carpeta raíz.
4. Sustituye el número de WhatsApp de demostración en `index.html` por el número real.

No requiere compilación, dependencias ni frameworks.
